# 0002. 평가 도구는 main의 `eval/`에 둔다

- 상태: 채택
- 날짜: 2026-11-12
- 관련: PR #11, `eval/README.md`

## 배경

PR Map의 정확도와 토큰 사용량을 재는 평가 도구를 어디에 둘지 정해야 했습니다. 별도 저장소, 평가 전용 브랜치, main의 폴더가 후보였습니다.

## 결정

평가 코드와 케이스는 main의 `eval/`에 둡니다. 실행 결과(`eval/results/`)는 커밋하지 않습니다.

## 근거

- 평가는 지금의 스키마와 `validate`를 기준으로 돌아야 합니다. 같은 곳에 있어야 스킬을 고치는 PR에서 케이스와 정답지를 함께 고칠 수 있습니다.
- 규칙을 바꾼 PR 안에서 점수가 어떻게 변하는지 바로 볼 수 있습니다.
- `eval/`은 `skill/pr-map/` 밖이라 설치되는 스킬에 들어가지 않습니다.
- 결과에는 분석한 저장소의 코드 원문이 들어가므로 커밋하지 않습니다. 정답지에는 동작 설명과 줄 번호만 있습니다.

## 버린 대안

- **평가 전용 브랜치:** main과 금방 어긋나서, 매번 리베이스하거나 옛 기준으로 재게 됩니다.
- **별도 저장소:** 스킬과 평가를 한 PR에서 함께 바꿀 수 없습니다.

## 다시 볼 조건

- 공개하면 안 되는 저장소의 PR을 케이스로 써야 할 때. 그 케이스만 비공개 저장소로 뺍니다.
- 케이스가 많아져 저장소가 눈에 띄게 커질 때
