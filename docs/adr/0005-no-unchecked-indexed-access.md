# 0005. `noUncheckedIndexedAccess`를 켠다

- 상태: 채택
- 날짜: 2026-11-13
- 관련: PR #14, `tsconfig.json`

## 배경

ESLint의 `no-unnecessary-type-assertion` 규칙을 넣자, `m[1]!`처럼 배열이나 정규식 결과를 인덱스로 읽은 뒤 붙인 단언 124곳이 "필요 없음"으로 잡혔습니다. `tsconfig.json`에는 `noUncheckedIndexedAccess`가 `false`로 적혀 있었습니다.

## 결정

단언을 지우지 않고 `noUncheckedIndexedAccess`를 켭니다.

## 근거

- 옵션을 켜면 걸리는 단언이 124곳에서 18곳으로 줄었습니다. 코드는 이미 이 옵션에 맞춰 쓰여 있었습니다.
- 켠 뒤 생긴 타입 오류는 `eval/`과 테스트의 3곳뿐이었습니다.
- 끈 채로 단언 124곳을 지우면, 값이 없을 수 있는 자리를 타입 검사가 더는 잡지 못합니다.
- 옵션이 왜 꺼져 있었는지는 기록이 없습니다.

## 다시 볼 조건

특별히 없습니다. 이 옵션 때문에 단언이 지나치게 늘어 코드가 읽기 어려워지면 다시 봅니다.
