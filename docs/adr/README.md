# 결정 기록

이 저장소에서 내린 결정과 그 이유를 적어 둡니다. 나중에 "왜 이렇게 했지?"를 코드나 커밋에서 다시 찾지 않기 위한 기록입니다.

## 언제 쓰나

아래에 해당하는 변경을 하면 같은 PR에 기록을 추가합니다.

- 숫자로 된 상한이나 기본값을 정하거나 바꿀 때 (파일 수, 줄 수, 턴, 비용)
- 도구나 방식을 골랐을 때. 특히 시험해 보고 버린 대안이 있을 때
- 규칙을 끄거나 예외를 둘 때
- 스키마, 검증 규칙, `SKILL.md`의 작성 규칙을 바꿀 때

버그 수정, 문구 수정, 리팩터링처럼 결정이 없는 변경에는 쓰지 않습니다.

## 쓰는 법

1. `0000-template.md`를 다음 번호로 복사합니다. 파일 이름은 `번호-짧은-영문-이름.md`입니다.
2. 항목을 채웁니다. 한 화면 안에 들어오게 짧게 씁니다.
3. 아래 목록에 한 줄을 추가합니다.

지킬 것이 두 가지 있습니다.

- **이유를 모르면 지어내지 않습니다.** "근거 기록 없음"이라고 쓰고, 알고 있는 사실만 적습니다.
- **기록은 고치지 않고 새로 씁니다.** 결정을 바꾸면 새 기록을 쓰고, 이전 기록의 상태를 `대체됨 (→ 번호)`으로 바꿉니다. 오타와 링크는 고쳐도 됩니다.
